# Задание 2. Интеграция с CI/CD и удалённым хранением состояния

## Подготовка
Необходимо [создать облачный бакет](https://yandex.cloud/ru/docs/storage/quickstart) в Yandex Object Storage и [организовать доступ через сервисный аккаунт](https://yandex.cloud/ru/docs/storage/s3/?from=int-console-help-center-or-nav).

## Worflow для GitHub Actions
Код: [deployment.yaml](../.github/workflows/deployment.yaml).

Workflow состоит из двух стадий "plan" и "apply". Первая является поставщиком плана развертывания (tfplan) для второй. Запуск специально сделан ручным для большей управляемости.

Безопасность обеспечивается зас счет использования GitHub secrets, которые передаются в исполнительные механизмы через envs.

## Модуль Terraform
Код: [vm_module](./vm_module/).

Принципиально отличается от предыдущего задания наличием [backend-а](./vm_module/backend.tf) для хранения состояния в удаленном хранилище. Он обеспечивает загрузку/выгрузку файла состояния (terraform.state) в предварительно созданном бакете Yandex Object Storage.

Безопасность обеспечивается зас счет передачи секретов через envs, безопасная доставка  которых обеспечивается механизмами CI/CD-системы.
