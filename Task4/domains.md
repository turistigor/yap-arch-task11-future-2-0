# Структура доменов

## Медицинский

**Значение для бизнеса**
- Продажа медицинских услуг - один из основных источников дохода.

**Поддомены:**

- Организационный (пациенты, врачи, расписание)
- Лечение (медкарты, анализы)

## Финансовый

**Значение для бизнеса**
- Поддержка других направлений финансовыми операциями.
- Продажа финансовых услуг - один из основных источников дохода.

**Поддомены:**

- Оплата
- Услуги (кредиты, вклады)

## ИИ

**Значение для бизнеса**
- Поддержка других направлений при помощи возможностей ИИ.
- Монетизируемые ИИ-продукты - одна из целей компании.

**Поддомены:**

- Поиск аномалий в данных
- Система принятия решений (снимки, лечение)
- Ассистенты (голосовой, заполнение карт)

## Данные

**Значение для бизнеса**
- Косвенное влияние на работу системы посредством решений, принимаемых на основе отчетов.
- Предоставлений персональной аналитики клиентам.

**Поддомены:**

- Продуктовая аналитика.
- Персональная аналитика.

## Безопасность

**Значение для бизнеса**

- Влияние на работу системы при обнаружении инцидентов.

**Поддомены:**

- Инциденты
